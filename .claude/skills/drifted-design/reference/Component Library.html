Components

Every component on Tar, in every state, built from the Stage 1 tokens only. No component invents a value; where you see a number here it exists in tokens/ and in the Tailwind config. Motion behaviour is noted under each set, and the compact spec sheet at the end is the build reference.

Large CTA — the only control that carries misregistration
Book the call Hover it — the Siren plate slips out behind

Decision: yes, but only here. The offset is a brand device, not a UI affordance — on small controls it reads as a rendering bug and hurts the hit target. On the page-level CTA (24/38px padding, 13px label) it earns its place: the plate rests in register and slips to −9, −8 @ −3.5° on hover in 160ms ease-hit, returning on leave. It never appears on primary, secondary, ghost, form controls or nav.

FAQ accordion · marquee
How fast can you start?

Two weeks from signature, and we will tell you on the first call if that slips. We only take two new clients a quarter so the answer is never "next month".

Do you work on retainer?

Retainer, project, or performance-linked. Most clients start on a three-month build and move to a retainer once the number is moving.

What if it isn't working?

You get a written review every month against the one number we agreed. If it stops moving for two months we either change the plan or end it — we do not run accounts on autopilot.
